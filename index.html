⚡ Panduan Setup Supabase Storage

Supabase menyediakan cloud storage gratis 1 GB yang sangat cukup untuk ratusan buku PDF pesantren. Ikuti 4 langkah mudah berikut (cukup sekali setup saja):

1. Daftar & Buat Project di Supabase:
Buka supabase.com, daftar/login akun gratis, lalu klik tombol "New Project" (contoh nama: bilal-tahfizh). Tunggu sebentar sampai project siap.
2. Buat Bucket Storage:
Di menu sebelah kiri, klik menu Storage → klik tombol "New Bucket" → Beri nama persis: buku-referensi → Aktifkan tombol "Public bucket" → Klik Save.
3. Salin URL & Anon Key API:
Buka menu Project Settings (ikon roda gigi di pojok kiri bawah) → pilih API → Salin dua data berikut:
  • Project URL (contoh: https://abcdefghijkl.supabase.co)
  • Project API keys → anon / public (kunci panjang yang diawali eyJ...)
4. Tempel & Uji Koneksi:
Tempelkan Project URL dan Anon Key ke form pengaturan di aplikasi ini, lalu klik tombol "🔌 Tes Koneksi & Simpan". Selesai!
💡 Catatan: Setelah Supabase aktif, setiap file PDF yang di-upload akan otomatis tersimpan di Cloud Supabase dan link publiknya dibagikan ke seluruh pengajar & orang tua secara real-time.
